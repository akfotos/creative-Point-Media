# Creative Point Media

A portfolio website for Creative Point Media — a multidisciplinary visual production studio in Accra, Ghana. Built with Next.js, Tailwind CSS, and Framer Motion.

## Live Site

**https://akfotos.github.io/creative-Point-Media/**

Deployed automatically to GitHub Pages on every push to `main` via `.github/workflows/deploy.yml`.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Commands

- `npm run dev` — Start the development server
- `npm run build` — Build the static site (outputs to `out/`)
- `npm run start` — Start the production server
- `npm run lint` — Run ESLint

## Pages

- `/` — Home
- `/projects` — Project grid with filters
- `/gallery` — Masonry gallery with lightbox
- `/services` — Capabilities
- `/about` — Studio story and stats
- `/contact` — Contact form and studio info
